# Week 4 - Computer Vision

## Overview
This week focused on learning the fundamentals of computer vision and image preprocessing techniques used in deep learning. The objective was to understand how images are loaded, processed, transformed, and prepared for computer vision tasks.

## Topics Covered
- OpenCV Basics
- Pillow (PIL)
- TorchVision Transforms
- UTKFace Dataset
- CelebA Dataset

## Notebooks

### 1. OpenCV Basics
- Reading and displaying images
- Image resizing
- Cropping images
- Color space conversion
- Drawing shapes and text
- Edge detection
- Image saving

### 2. Pillow Basics
- Opening images
- Resizing and rotating
- Cropping images
- Image enhancement
- RGB channel operations
- Saving processed images

### 3. TorchVision Transforms
- Resize
- Center Crop
- Random Crop
- Horizontal Flip
- Vertical Flip
- Color Jitter
- ToTensor
- Normalize
- Compose

### 4. Face Datasets
- Introduction to UTKFace Dataset
- Introduction to CelebA Dataset
- Dataset structure
- Applications in face analysis and face aging

## Learning Outcome
By the end of this week, I gained practical experience with image preprocessing, data augmentation, and face datasets, providing the foundation required for building deep learning models for computer vision and face aging tasks.
