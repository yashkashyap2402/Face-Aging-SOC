# Week 5 - Generative Adversarial Networks (GANs)

## Overview

This week focused on understanding Generative Adversarial Networks (GANs), one of the most important deep learning architectures for image generation. A basic GAN was implemented using PyTorch and trained on the MNIST handwritten digit dataset.

---

## Objectives

- Understand the working of GANs.
- Learn the roles of the Generator and Discriminator.
- Study adversarial training.
- Build and train a basic GAN on the MNIST dataset.
- Generate synthetic handwritten digit images.

---

## Topics Covered

- Introduction to GANs
- Generator Network
- Discriminator Network
- Random Noise Vector
- Adversarial Loss
- GAN Training Loop
- Image Generation
- MNIST Dataset
- PyTorch Implementation

## Notebook Description

### gan_basics.ipynb

This notebook covers the theoretical concepts of Generative Adversarial Networks.

Topics include:

- Discriminator
- Random Noise
- Adversarial Training
- GAN Loss
- Applications of GANs
- Advantages and Limitations

---

### mnist_gan.ipynb

This notebook implements a complete GAN using PyTorch.

The implementation includes:

- Loading the MNIST dataset
- Building the Generator network
- Building the Discriminator network
- Binary Cross Entropy Loss
- Adam Optimizer
- GAN Training Loop
- Image Generation
- Saving the trained Generator model
