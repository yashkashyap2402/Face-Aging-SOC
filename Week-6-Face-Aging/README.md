# Week 6 - Face Aging using CAAE

## Overview

This week focused on understanding Conditional Adversarial AutoEncoders (CAAE) and Age-Conditional GANs, which are widely used for facial age progression and regression. The objective was to understand the architecture behind face aging models and explore an existing implementation from a public GitHub repository.

## Topics Covered

- Conditional Adversarial AutoEncoder (CAAE)
- Conditional GANs
- Latent Space Representation
- Age Conditioning
- Face Aging Pipeline
- Project Repository Structure
- Dataset Preparation
- Model Training Workflow

## Files Included

- `caae_basics.ipynb`
- `age_conditional_gan.ipynb`
- `face_aging_project_setup.ipynb`

## Learning Outcome

Developed an understanding of face aging architectures based on CAAE and conditional GANs, explored an existing implementation, and learned the workflow required to set up and run a face aging project.
